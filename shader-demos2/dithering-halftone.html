技術原理

側臉的輪廓先在 JavaScript 裡以曲線取樣成多邊形，逐格算出有號距離場，再把距離轉成圓鼓的高度場並加上耳、顴、眉的起伏；著色器用高度場的梯度當法線，讓一盞緩慢繞行的光打出明暗與投在牆上的影子。得到的灰階不直接輸出，而是交給兩種印刷手法之一：8×8 Bayer 有序抖動（每格只有墨或紙）或 45° 旋轉網格的調幅網點；紅日是另一塊獨立的版，用不同角度與錯位疊印，最後加上紙纖維與油墨暈開。

核心參數

手法：在 Bayer 抖動與網點之間切換。網格：網點或抖動格的大小，以 CSS 像素計，在高解析度螢幕上仍清楚可見。對比：送進網版前的灰階曲線，越高越像影印過頭的傳單。

適合的位置

適合活動或展覽海報頁、獨立刊物與 zine 的封面、需要立場與態度的品牌宣言頁首；只有三色，標題可直接用黑或紅壓在留白處。
