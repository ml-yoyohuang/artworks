# 入口碟片尺寸 A/B 對照

本地預覽：`http://localhost:8000/interval/studies/disc-scale/`。獨立方向稿，正式首頁未修改、未發布。

- A：沿用目前鏡頭前移；碟片實際比例為 100%。
- B：hover 同 A；click 時額外於 1250 ms 內放大至 120%。
- 共用真實 MuseumWorld、相同取景及 1.8 米 hover／4.5 米 click 鏡頭偏移。
- 碟片動態時間於 click 重置，以比較同一段材質與形變。前移／放大完成，停 160 ms，再淡出；這個預覽不進入展廳，停在淡出畫面供重播。
- 單一 WebGL canvas；淡出完成或背景分頁時停止更新，切換／重置恢復；不載入各展廳作品。
- 減少動態取消前移與額外放大，直接淡出。支持鍵盤及觸控。

Chromium 151.0.7922.34／SwiftShader，1440×900 桌機、390×844 觸控模擬：A=100%／B=120%、兩版鏡頭一致、hover 尺寸相同、重播復位、播放途中切換取消、單一畫布、淡出後停止 RAF、減少動態及無頁面／HTTP 錯誤通過。已檢視桌機與手機截图；未用實體手機。
