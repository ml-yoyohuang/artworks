# 入口鏡頭上仰 A/B 測試

本地預覽：`http://localhost:8000/interval/studies/camera-tilt/`。獨立測試，正式網站維持 A，碟片沒有額外放大。

- A：目前的純前移。
- B：click 同步前移與上仰 3°；左右朝向固定。
- 兩版共用真實入口場景、相同鏡頭前移（hover 1.8 米／1000 ms；click 4.5 米／1250 ms）、停留 160 ms 與淡出。Hover 不上仰。
- 上仰與前移都於 click 同時開始，在 1250 ms 內完成。僅在此測試頁繪製時調整觀看角度，實際前移路徑與正式 MuseumWorld 原始碼不變。
- 播放後停在淡出畫面，可重置、重播、切換 A/B；重置恢復原角度。減少動態直接淡出，背景時停止更新。單一 canvas，不載入作品或展區。

Chromium 151.0.7922.34／SwiftShader：1440×900 桌機、390×844 觸控模擬已檢視。逐幀確認前 400 ms 已開始上仰，1250 ms 後達 3°，碟片比例皆為 100%、左右朝向相同，取消／復位／減少動態通過，無頁面或 HTTP 錯誤及水平溢出。未使用實體手機。

`desktop-a.png`、`desktop-b.png`、`mobile-a.png`、`mobile-b.png` 為淡出前完成構圖；擷取時僅隱藏測試頁遮幕與重播提示，以查看兩版視野。
