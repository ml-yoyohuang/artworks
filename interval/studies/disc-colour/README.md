# 入口碟片・八版配色研究

啟動專案靜態伺服器後開啟 `http://localhost:8000/interval/studies/disc-colour/`。

- A：原始入口配色。
- B：青藍、青紫明亮冷光為主，少量洋紅、金色局部點綴；保留原螺旋流動、形變、材質及外輪廓，朝向偏色輕於出口。`palette.js` 維護新色票與光譜映射。
- C：中性霧白純色，主色 `#e1e6e8`、冷灰暗色 `#aebac3`、亮色 `#f0f2f2`。用色票控制的柔階材質避免入口暖光與色調映射染黃，保留形變與柔和光影，停用螺旋配色及虹彩。
- 八版都使用孔洞直徑：環帶徑向厚度＝1：1.618（外半徑4.6、孔半徑約1.086、環帶徑向厚度約3.514），正面參數化比例，觀看透視和形變會影響視覺尺寸。正式本地入口已採用 B/C/F/G/H 等機率隨機選擇，返回入口保留版本。
- 可切換、暫停、重播、拖曳及方向鍵環顧、重設視角。比較視角偏色時先暫停；版本切換保留朝向，從相同時間點重播。
- 一個 MuseumWorld、一個 WebGL context、同一網格；A/B 共用原虹彩材質，C 額外一個中性霧白材質，切換時重用，不增開畫布或影片；背景暫停、減少動態、離頁釋放、WebGL 備援入口實際截圖。

Chromium151／macOS／SwiftShader，1440×900桌機、390×844手機觸控模擬；未使用實體手機。驗證工具 `tools/verify-disc-colour.cjs`，可指定 PLAYWRIGHT_MODULE、INTERVAL_STUDY_URL。涵蓋八版像素差異、C色碼、動態、視角、鍵盤、背景暫停、減少動態、重播、十六次版本切換資源穩定、單一畫布、無溢出與備援。結果 `qa-disc-colour-results.json`，截圖 `screenshots/*-disc-colour-*.png`。

本次研究頁及孔洞調整尚未提交、推送或公開發布。

## 外輪廓形變研究

八版共用同一外緣形變，由正式 `js/disc-outline.js` 維護。兩個低頻角向波以不同速度變化，外緣額外伸縮上限約±16%，向內平滑遞減至零，孔洞邊緣固定；原表面凹凸形變保留。外緣持續緩慢鼓起與收回，重新計算法線並對齊環形接縫，沒有增加材質或 context。

1：1.618 是未形變網格的設計比例，動態外緣會讓局部環帶寬度變化。正式本地首頁五版已採用確認的外緣形變。

## 新虹彩配色提案

| 版本 | 色彩方向 | 主色起點 |
|---|---|---|
| D 檸金嫩綠 | 檸金 → 嫩綠，輕盈暖光 | #e0e090／#a4e7a7 |
| E 翡翠冰藍 | 翡翠綠 → 冰藍，清澈極光 | #90e09d／#a4d9e7 |
| F 鈷藍洋紫 | 鈷藍 → 洋紫，冷冽異質感 | #909de0／#dea4e7 |
| G 玫瑰蜜橘 | 玫瑰粉 → 蜜橘，柔暖珍珠感 | #e090bf／#e7c3a4 |

色票集中於 `js/disc-palette.js` 的 DISC_PALETTES，代理檔只轉出共用資料與函式；只維持一個網格，新增配色切換頂點色，不並行運行多個碟片。D/E 僅供研究，F/G 已納入正式首頁隨機候選。

D～G 以 B 的整組色票作 HSL 色相旋轉，保留各色的彩度與明度；兩個主色色相跨度約 62°（B 約 183° → 245°），D 約 60° → 122°、E 約 130° → 192°、F 約 230° → 292°、G 約 325° → 27°，皆沿同一方向跨色，少量配角色也一起旋轉。此為色票座標的比較，實際虹彩、光線與螢幕會影響觀看感受。B/C、孔洞比例、形變、螺旋與視角偏色設定維持原樣。

## H 藍莓乳霜

新增藍莓靛紫 `#7374ba` → 淡莓紫 `#bda1d6`，莓紫與冷調乳霜作點綴；比 F 的鈷藍／洋紫更濃郁，避免金綠點綴干擾藍莓口味感。H 使用同一虹彩材質、螺旋、外輪廓形變與視角偏色，只增加色票及切換入口，已納入正式首頁隨機候選（B/C/F/G/H 各 20%）。
