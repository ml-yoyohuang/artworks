# 世界尚未對齊：標準字方向比較

本地預覽：從專案根目錄啟動靜態伺服器，開啟 `/interval/studies/title/`。獨立比較稿，不修改正式首頁。

- 00：現有標題對照。
- A：尚、未依序偏離基線。
- B：尚、齊的筆畫留細縫。
- C：尚未微偏移，齊留一道細縫。

點「放入入口比較」切換下方情境。入口背景為現有 WebGL 空間實際擷取的靜態畫面；情境預覽不是可操作展場。

方向稿採網站宋體設定，以 HTML/CSS 排字及裁切比較，尚未逐筆重繪字形。定案後再製作固定輪廓的向量標準字與小尺寸版本。

Chromium 桌機 1440×1100、手機 390×844 排版模擬已檢視；四版切換、單一選取狀態、无水平溢出及頁面錯誤檢查通過。未使用實體手機。`variants.png` 是黑白比較；`context-*.png` 是三版入口情境；`comparison.png`、`mobile-comparison.png` 為完整比較頁。

點「查看 C 的進場動畫」前往情境。情境進入視窗時播放一次，完成後保持靜止；可用「重播 C 動畫」反覆比較。

- 尚、未：延遲 70 ms，640 ms 下移至 0.055em。
- 齊：延遲 300 ms，上下兩段於 460 ms 內分離，形成 0.017em 的間隙。
