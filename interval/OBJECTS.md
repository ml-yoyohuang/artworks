# 場景物件名稱對照

本表對應目前本機版本。這些是之後溝通場景修改時使用的中文名稱，不是另加在畫面上的標籤。以各展區入口朝出口方向定義左右、前後；轉動鏡頭後仍沿用同一名稱。成組物件由入口往深處編號。作品則使用原作名稱。

## 全館共用

| 名稱 | 指的是 |
|---|---|
| 展區地板 | 觀眾腳下的主要行走面；第二區另分成三片平台 |
| 作品畫面 | 顯示原作品停格的正面 |
| 作品背板 | 作品畫面後方、略露出邊緣的薄板 |
| 作品標籤 | 作品下方有序號、名稱及箭頭的按鈕 |
| 觀看位置圓環 | 地面上的定點移動標記 |
| 作品資訊卡 | 點擊作品後出現的文字及「進入作品」面板 |
| 底部接觸陰影 | 底座附近的柔和陰影效果，並非另一片實體地板 |
| 環境光 | 全館整體明暗與冷暖 |
| 主方向光 | 從高處照入、形成主要光影的光源 |
| 遠景霧 | 遠方淡化及空間深度效果 |

第一區另有每件作品的「左吊線」「右吊線」。第三、第四區每件作品另有「作品底座」「作品支撐柱」，可用原作名稱指定，例如「《顯影》的作品支撐柱」。

## 入口：暮色中的步道

- 入口步道：霧白長道路。
- 第一階梯薄板、第二階梯薄板、第三階梯薄板、第四階梯薄板：從步道往碟片方向，依距離及高度編號。
- 虹彩碟片：高處持續形變、帶螺旋冷光的環形薄膜。
- 步道左邊線、步道右邊線：道路兩側的細線。

## 第一區：風的測量室

- 展區地板。
- 左側牆頂：左側牆與上方長頂板組成的一體結構；指定部位時可說「左側牆頂的牆面」「左側牆頂的頂板」。
- 右懸浮頂板：右上方較窄的獨立長薄板。
- 第一左隔板、第二左隔板：左側兩片豎向隔板。
- 每件作品的作品畫面、作品背板、作品標籤、左吊線、右吊線。
- 觀看位置圓環。
- 第一出口門廊：前往第二區，詳見出口表。

作品：順風千行、靜默測繪、黃昏群舞、字散、銅版星圖。

## 第二區：共處的平面

- 前段地板平台、中段地板平台、後段地板平台。
- 第一平台間隙、第二平台間隙：前／中及中／後平台之間的空隙，並非實體物件。
- 左橘色色牆：前段左側的大橘色牆面。
- 右橄欖色色牆：中段右側的大橄欖色牆面。
- 前段門框：入口附近的石灰色ㄇ字門框。
- 深處門框：《門後還有門》附近的第二道石灰色ㄇ字門框。
- 第一組左隔板、第一組右隔板：前段的一對石灰色隔板。
- 第二組左隔板、第二組右隔板：下一對灰綠色隔板。
- 第三組左隔板、第三組右隔板：再往深處的一對石灰色隔板。
- 第四組左隔板、第四組右隔板：深處的兩片灰綠色薄板。
- 門框腳邊柔影：兩道門框腳邊的局部接觸陰影效果。
- 懸浮橘色門板：高處持續浮動、帶傾角的橘色薄板。
- 門板深色嵌面：懸浮橘色門板上的小黑色長方形；與門板一起浮動。
- 每件作品的作品畫面、作品背板、作品標籤。
- 觀看位置圓環，其中另有「懸浮門板觀看位置」。
- 第二出口門廊：前往第三區，詳見出口表。

作品：讓出一寸、三色未合、背面也是顏色、缺席者的散步、讀過的厚度、晚到的那幾位、門後還有門、它剛剛在這裡、切分的秩序、漆金結。

## 第五區：薄處有光

- 展區地板。
- 齊平觀看區：中央偏前方、與地面同高的不同色材質區域。
- 終廳背牆頂板：主作品後方背牆與上方頂板的一體結構；指定部位時可說「終廳背牆」「終廳頂板」。
- 左側牆、右側牆：兩翼的長牆。
- 左翼隔板、右翼隔板：兩翼靠近前後作品之間的豎向隔板。
- 左觀看長凳：包含長凳座面、長凳支座。
- 長凳接觸陰影。
- 每件作品的作品畫面、作品背板、作品標籤。
- 觀看位置圓環、終章觀看位置。
- 終章選單：返回入口、繼續參觀、全部作品的結尾面板。

作品：薄處有光、隔著玻璃、午後泳池、紗上波紋、石膏習作。

## 四個出口門廊

門框及後方門廊目前是同一個連續模型，但仍可按可見部位描述需求。

| 名稱 | 指的是 |
|---|---|
| 出口門框 | 正面ㄇ字輪廓；可細分左立邊、右立邊、上橫邊 |
| 門廊左內牆、門廊右內牆 | 門框往深處延伸的兩側牆面 |
| 門廊頂面 | 門廊上方的內側天花板 |
| 門廊背牆 | 最深處的整片方形牆面 |
| 門廊地面 | 展區地板延伸進門廊的部分 |
| 門廊柔光 | 門廊上方內部的光源及其柔和光感 |
| 下一廳提示牌 | 出口旁顯示下一展區名稱和敘述的介面 |

出口專屬物件：

- 第一出口：門廊橘色色板。
- 第二出口：沒有額外裝飾物件。
- 第三出口：左半透明薄板、右半透明薄板。
- 第四出口：深灰藍虹彩薄膜牆（原稱黑色薄膜），覆蓋門廊背牆，青藍與青紫窄光帶圓潤翻捲，隨拖曳視角柔和偏色。

## 描述方式

使用「展區＋物件名稱＋調整」即可，例如：

- 第二區第四組右隔板，往右移一點。
- 第三區承托頂板，縮小但保留枝狀承托。
- 第一出口門廊頂面，暗一點。
- 《校樣之晨》的作品支撐柱，縮窄一點。

目前第二、第四區沒有入口頂板；第五區沒有突起的中央觀看薄板。第二區的懸浮橘色門板、左橘色色牆、第一出口的門廊橘色色板是三個不同物件。《門後還有門》作品、第二區兩道門框、第二出口門框也各自不同。
