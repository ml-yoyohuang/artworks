# 《從白晝走進暗房》線上 3D 展間 — 交付報告

完成日期：2026-10-09。入口：`showroom/index.html`（須經靜態伺服器開啟，見 [README.md](README.md)）。

## 展覽結構與陳列理由

路線為「規則生成形狀 → 光生成影像」，空間由白晝一路暗下，觀眾在暗房盡頭與一張顯影中的相片相遇。

| 空間 | 尺寸與光 | 陳列 |
| --- | --- | --- |
| 入口大廳 | 14 × 11 m，挑高 7 m，大面積天窗 | 不陳列作品。牆面只有展名與藝術家／作品數，HTML 層顯示策展論述、載入進度與「進入展覽」。 |
| 第一廳「規則的花園」 | 14 × 26 m，高 5.2 m，中央天窗槽、白牆、淺色清水混凝土地 | 10 件 p5.js 作品，細黑框＋白色卡紙，以等面積（約 0.74 m²）掛於 1.55 m 視線高度；東西兩牆交錯，每面牆間距 4 m；中央一張長凳。 |
| 長廊「光的退場」 | 3.5 × 22 m，高 3.6 m | 只在盡頭牆面陳列〈光走過的路〉（long-exposure）。 |
| 第二廳「暗房」 | 16 × 38 m，高 4.6 m，全黑、拋光深色地坪 | 14 件 GLSL 作品以燈箱（1.76 × 1.10 m）南北交錯排列在中軸兩側。 |
| 終點 | 暗房最深處西牆，正對入口中軸 | 〈銀鹽的第二次黎明〉（darkroom-solarize）單獨陳列（2.56 × 1.60 m），前方一張黑色長凳。 |

**第一廳順序**：風的手稿 → 無名的海拔 → 房間與停頓 → 柔軟的擁擠 → 慢慢展開的內側 → 朝光的分歧 → 引力的銅版 → 結的方向 → 共同的偏航 → 字的餘溫。由「風」這種最輕的規則開場；前七件是淺色紙面，最後三件是靛藍、深海與紫黑底色，展廳本身在接近長廊時預先調暗，讓明暗轉換從作品內部就開始。以〈字的餘溫〉收尾，作為進入無字暗房前的最後一段文字。

**暗房順序**：日光的標本 → 偏移的花園 → 紙上的氣候 → 兩個日落之間 → 一處皺摺 → 石頭裡的潮汐 → 觸摸一池字跡 → 透明的重量 → 尚未命名的生命 → 緩慢佔領 → 遲到的光 → 一個不存在的物件 → 有限的灰階 → 失序的肖像 → 終點〈銀鹽的第二次黎明〉。從仍帶有日光與印刷記憶的藍曬、套色與紙張開始（銜接第一廳的版畫），經過布、石、水、玻璃等物質，再到生命、記憶與深空的虛無；最後兩件與終點作品共用同一張虛構肖像，三張臉在中軸盡頭依序被網點化、被排序打散，最終在暗房顯影——呼應展覽起點「一條規則落在紙上」。

**長廊**是整個展覽的儀式段落：牆、地、天花的反照率沿長度烘焙成白 → 灰 → 黑的連續曲線；七盞嵌燈亮度逐盞遞減，地面光圈隨之消失；全域天光、環境反射與曝光依觀眾在長廊中的位置連續變化（並以時間平滑，不會跳變）；介面文字、暈影與顆粒同步由淺色轉為暗色。盡頭的長曝光作品從第一廳門口就能看見，是唯一的發光體。

## 技術

- **three.js 0.186.1（r186）**，從 npm registry 下載釘選版本 tarball（SHA-256 `8cd06870…3fe7`），未修改地複製到 `vendor/three/`（含 MIT `LICENSE` 與來源說明）。以 import map 指向本地相對路徑，**不從任何 CDN 載入**。
- 無建置工具；showroom/ 可被任何靜態伺服器直接提供。本地開啟：在 repo 根目錄執行 `npx serve .` 或 `python3 -m http.server`，開啟 `/showroom/`（詳見 README）。以 `file://` 開啟時頁面會顯示說明而非空白。
- 建築幾何全部以程式建立；材質（混凝土、灰泥、環境遮蔽、長廊漸層、光暈、牆面文字與作品標籤）皆以 Canvas 程序生成，無外部 3D 模型、圖片或字型。
- 光影：第一廳以半球天光＋柔和方向光（PCF 軟陰影，靜態場景只更新一次陰影圖）＋ RoomEnvironment 低強度環境反射；牆角、踢腳線、天花轉角與長凳下方的環境遮蔽、天窗下的光池烘焙在 aoMap 中。ACES Filmic 色調映射；作品本身不經色調映射以保留原色。CSS 暈影與極輕微的動態顆粒（減少動態時停止）。
- 暗房：每件作品是燈箱（不受光照的影片材質），另有牆面光暈與地面溢光；**固定數量的 RectAreaLight 池**（高 6／中 4／低 2）每影格重新分配給最近的燈箱，顏色取自作品影片的即時平均色（每 220 ms 以 8×5 畫布取樣並平滑），名次交換處以距離淡入淡出，不會跳燈，也不會重新編譯著色器。地坪低粗糙度，呈現作品色光的柔和反射。
- 作品影片：只在附近（第一廳 12 m／暗房 15 m／終點 30 m 內）、位於正面且在視錐內的作品播放，同時最多 6／4／3 段；其餘暫停並保留最後一格。分頁隱藏時停止渲染並暫停全部影片。
- 載入：大廳先載入 three.js 與第一廳 10 張海報圖並顯示進度；進入後才以閒置時間載入其他海報；影片依距離延遲建立。
- 品質分級：依指標裝置、核心數、記憶體與 GPU 名稱選擇高／中／低（像素比上限 2／1.5／1、陰影、面光源數、同時播放數、反鋸齒），並在影格率持續低於目標時逐步降低像素比。`?quality=` 可強制等級。
- 無障礙：全部操作可用鍵盤完成（見 README）；所有按鈕具清楚的 `:focus-visible` 外框；對話層有焦點循環與 Esc 關閉；導覽圖作品為可聚焦的按鈕；不支援 WebGL 時自動進入作品列表。`prefers-reduced-motion` 下，鏡頭移動改為淡出淡入切換，作品只在被觀看時播放。
- 無任何音效或音樂。

## 作品短片

以 Playwright（Chromium、ANGLE Metal）在本機伺服器上錄製，隱藏原頁介面只留作品畫布。shader 與共同的偏航以 CDP screencast 實時擷取；九件會生長完成的 p5 作品以 DPR 2 截圖擷取（生長以時間為準，因此不受擷取速度影響），並依內容自動裁切到作品範圍加紙面留白，保留各自比例（1.0–1.6）。之後以 ffmpeg 編碼：

- 持續動畫（13 件 shader＋Boids）：8 秒無縫循環，以尾段 1.2 秒交叉淡入開頭；互動型作品（Boids、觸摸一池字跡、遲到的光）錄製時以週期 8 秒的游標軌跡驅動，使互動本身也循環。
- 生長型（9 件 p5）：14 秒生長加速 2.6 倍（約 5.4 秒）＋完成畫面停留 2.6 秒＋0.7 秒淡回空白紙，共 8.7 秒。尚未命名的生命、緩慢佔領、銀鹽的第二次黎明同樣以「生長／顯影 → 停留 → 淡回」循環（9.8–10.2 秒）。
- VP9 webm（constrained quality）＋ H.264 mp4 備援＋ webp 海報。26 件全部 < 2 MB（最大：石頭裡的潮汐 webm 1.20 MB／mp4 1.41 MB）。`media/` 合計 20 MB；showroom/ 全部 22 MB（目標 60 MB 以內）。

### 自我評審與修正

逐張檢視截圖後做的修正：大廳的 3D 牆面標題原本落在 HTML 標題後方造成重影，改為門右側；地坪接縫過深像磁磚，調淡；天花板過灰，加入隨天光變化的漫射；第一版長廊在中段就全黑，重寫反照率曲線與天光衰減起點，使白→灰→黑在 22 m 內連續；暗房牆面幾乎不受作品光，提高面光源強度、牆面反照率、光暈與溢光；未播放的影片顯示為黑色（three.js VideoTexture 只在新影格上傳），改為影片實際出畫後才替換海報並在暫停時保留最後一格；導覽圖在寬螢幕改為橫向；說明卡淡出期間仍可被 Tab 選到，改為立即 `inert`；指標鎖定被拒絕與觸控 pointer capture 時的例外加上防護。

## 自行做出的重要決定

1. **空間為 L 形**：暗房接在長廊盡頭左側，讓長廊盡頭的牆只屬於長曝光作品；轉身進入暗房時，中軸 38 m 外正是終點作品。
2. **p5 作品依淺→深排列**，讓第一廳本身參與明暗過渡。
3. **p5 錄影自動裁切**：原頁為下方說明預留空白，直接錄製會讓作品偏上；裁切到內容加 15% 紙面留白後以版畫比例裝框。
4. **作品不經色調映射**，避免 ACES 改變作品原色；建築仍使用 ACES。後製（暈影、顆粒）以 CSS 疊加而非額外的渲染通道，成本極低且在所有等級都可用。
5. **反射**：以 RectAreaLight 在低粗糙度地坪上的鏡面反射與溢光貼片表現，不使用額外渲染整個場景的鏡面反射器，以維持手機效能。
6. **減少動態時作品只在被觀看時播放**，其餘顯示海報。
7. **iframe 中隱藏原頁的「返回目錄」連結**（只在檢視器內注入樣式，不修改原檔），避免觀眾在覆蓋層內離開；若仍導向目錄頁，檢視器自動關閉回到展間。
8. 長廊廳名定為「長廊｜光的退場」；作品英文副標沿用原頁。
9. 測試用 `window.__showroom` 掛鉤保留在程式中（唯讀用途，便於日後自動化驗證）。
10. 驗證期間 Python `http.server` 曾意外結束（原因未確認），之後改用支援 Range 請求的 Node 靜態伺服器完成全部驗證；README 仍列出兩種開啟方式。

## 已知限制

- 未在實體手機、iOS Safari 或 Firefox 實測；手機數據為 Chromium 尺寸／觸控模擬。iOS Safari 不支援指標鎖定，自由行走在 iOS 以搖桿與拖曳操作。
- 錄製短片為作品的一段時間切片；互動與隨機性只在「進入作品」的原頁中完整呈現。
- 展間以 `../p5-demos/`、`../shader-demos/` 相對路徑開啟原作，必須從 repo 根目錄提供；只單獨發布 showroom/ 時「進入作品」會失效。
- 自動降解析度只往下調整，不會回升；大幅改變視窗後重新整理即可回到預設等級。
- 〈緩慢佔領〉循環為 10.2 秒，略長於持續動畫的 6–10 秒範圍；它屬於生長型作品，保留完整的生長與停留。
