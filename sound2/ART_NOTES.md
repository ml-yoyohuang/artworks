# 接得剛剛好 Caught on the Beat — 十件作品藝術草案

寫於編碼之前，作為實作的目標；最終狀態以 README 與 QA_REPORT 為準。

展覽共通：作品滿版，外殼安靜（左上標題、右上導覽、底部一排膠囊控制）。一份樂譜同時驅動聲音與畫面。愉快感來自時間差：交棒、等待、差一點、追上、剛好一起。每件的底色明度與材質都不同，避免十頁同一張臉。
