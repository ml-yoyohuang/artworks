## 作品

以日系文具桌與編輯式排版構成可操作的萬花尺。暖白紙、透明塑膠齒輪、細線墨水與大字斜體共同構成視覺系統。開場範例是真實可匯出筆跡；新朱紅筆使用不同孔位，鼓勵第一次操作就嘗試疊圖。

已完成齒圈／齒輪／孔位／墨水選擇、滑鼠與觸控拖曳、鍵盤旋轉、自動繪圖、速度、暫停與恢復、停止、疊圖、整筆復原與重做、清紙確認、齒輪顯示切換、PNG 與 SVG 匯出。

採 TypeScript + Vite + 原生 DOM，因畫面主要是精密幾何與幀更新，沒有需要加入 UI 框架的複雜頁面資料流。Canvas 負責細線與快取，SVG 負責可互動齒輪；運動與筆尖共用同一幾何狀態。架構、公式、檔案結構與啟動方法見 [README](README.md)。

## 實際限制與擴充

目前沒有跨重新整理的作品保存；請先匯出。包含背景的匯出使用純暖白，不包含螢幕紙纖維。齒形是視覺近似，滾動數學按節圓準確計算。幀時間是本機 Chromium 量測，不能代表所有手機效能。

尚未在實體手機、Safari／Firefox 或螢幕閱讀器完整驗收；目前有語意控制、焦點、ARIA 狀態、對話框焦點、鍵盤替代、減少動態與觸控測試，沒有宣稱完整 WCAG 認證。
