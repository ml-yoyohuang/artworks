## STAGE 3 延伸

模型 2 的 type 明確決定造形／色系：forager 保留橘藍豆形；grazer 使用基因角數產生圓角多邊形、藍綠色系；generalist 用基因瓣數產生單一連通的柔和輪廓、粉橘色系。後兩者的顯示頂點面積先歸一，圓角／平滑仍會讓實際像素面積略有差異，不能當精密生物量量尺；引擎 mass 一律取 size²。角與瓣不是額外感測器。各系配色仍由中性 markers 決定。肖像與祖先預覽沿用同一份造形函式；點選半徑涵蓋顯示外緣，沒有新增碰撞物理。

背景 texture 的 R/G/B 通道保存 resourceA/capA、fertilityA、resourceB/capB。A 決定藍色水域，B 增加綠色水／地表暈染，不把可視紋理當作精確資源計數；精確比例各別顯示於筆記。零容量池紋理貢獻零。保留可重用的 WebGL／2D 暫存。

筆記新增逐類人口曲線、A/B 資源、攝取／代謝 interval rate、角數／瓣數頻率與平均歷史。時間軸用真 tick，缺漏資料斷線而非補零。現場 rule-based log、可取消比較與 JSON 匯出、3 個完整 checkpoint、譜系與完整 genotype 按需展開。祖先肖像的能量固定 50% 且速度零，明確註明是基因造形預覽，不聲稱歷史生理狀態。舊 v1 祖先無基因時不產生假預覽。詳細規則見 `LINEAGE_MODEL.md`。

## 模組界線

- `src/sim` 維持無 DOM 的科學引擎；本次僅替 Clock 新增清除累積相位的方法，沒有改變 step、遺傳、死亡、取食或能量規則。
- `main.ts` 讀取狀態；介入經 `setEnvironment`、`introduce`、快照替換進行。
- `creatures.ts` 依 ID 保存前一 tick 姿態、插值、形狀與 sprite；畫面不消耗模擬 RNG。
- `field.ts` 讀取 resource 與 fertility，WebGL 顯示平滑場；無 WebGL 時使用可重用的 2D 暫存畫布與 ImageData。
- `observation.ts` 定義 seed 解析、tick 座標與滅絕時間查找，供介面與回歸測試共用。

## 視覺屬性來源

| 表現 | 真實資料 | 分類／注意事項 |
|---|---|---|
| 身體尺寸 | `ph.radius`，源於 size 基因 | 功能性遺傳特徵；顯示放大 1.5 倍；面積亦受造形變化影響 |
| 拉長、尾長 | maxSpeed | 功能性特徵的視覺比喻；沒有獨立尾巴物理 |
| 側邊凹陷 | offspringInvest | 遺傳參數的裝飾映射，非繁殖器官 |
| 輪廓波動 | 控制器部分權重 | 權重在引擎有功能，映射成輪廓只作裝飾，不能稱為形態適應 |
| 藍／橘色調 | markerB / markerA | 中性、可遺傳；不是物種定義或親緣鑑定 |
| 核心大小 | energy / capacity | 暫時生理狀態；保有最小可見尺寸，不是精確面積量尺 |
| 位置／朝向 | x / y / heading | 真實運動，最後一 tick 插值；固定步進與繪圖分離 |
| 尾部節奏、振幅 | speed | 速度驅動的表現；肖像亦依速度，靜止時振幅為零 |
| 觸鬚 | senseRange / sensorAngle | 長度壓縮至 0.26 倍且附裝飾彎曲；選取虛線才是實際取樣方向與距離 |
| 出生／死亡 | 畫面間 ID 出現／消失 | 出生要求可見父代；可能略過兩幀間完成的整段生命。效果不用作計數依據 |
| 水域與沉積 | resource / cellCapacity、fertility | 經平滑及裝飾扭曲；精確總資源比例使用 sampleNow，以 fertile capacity 為分母 |

基因在生命期間固定，因此幾何與顏料可以快取。個體肖像以 WeakMap 快取，避免每幀重畫最多 700 個顏料點，亦避免快取永久保留死亡物件。子代繼承並突變同一組基因，所以會相似；未新增任意外觀隨機基因。

配色由 `palette.ts` 統一提供給生物、肖像與檢視色票。橘色新增桃橘、杏橘、柔琥珀，藍色新增水藍、霧藍、矢車菊藍，加上原有基準，每族四個色相／飽和度／明度錨點。markerA / markerB 在錨點間連續內插，維持小突變的漸進外觀；不是八種固定皮膚或新增物種。沒有新增基因或改變生存規則。舊快照仍可讀取，但使用更新後的配色映射。

## 時間與實驗重現

1× 目標為 30 ticks/s，提供 4×、16×、64×。每個執行 tick 使用同一套規則。每幀約 11 ms 的模擬預算是盡力而為，8-tick 批次可能超出預算；未執行的牆鐘時間不補跑，介面顯示目標及實際 tick rate。Clock 本身也有 burst cap。這些只影響實際速度，不縮減科學步驟。

隱藏頁面停止模擬與繪圖，回到前景不追趕背景時間。出生（約 2/3 秒）和死亡（約 0.9 秒）效果使用未暫停的可見時間，不再以畫面數計時。暫停凍結效果與姿態；減少動態偏好移除裝飾效果，真實運動繼續。

seed 包含有效的 0，URL seed 只描述初始世界。環境介入與釋放會寫入引擎事件，完整繼續需儲存快照；既有事件紀錄最多 500 筆，不是無限重播日誌。隨機釋放使用介面亂數生成基因，因此不能只憑初始 seed 重播介入。重設與開啟快照皆先警告會取代世界。

## 統計與可及性

歷史曲線按真實 tick 位置繪製，避免壓縮歷史後錯置時間；各曲線尺度、單位、樣本時間與標準差以文字補充。當下資源與平均能量使用 sampleNow；其餘趨勢與出生／死亡率來自最後的歷史樣本。Diversity 為逐 locus 原始基因變異的平均，不是 heterozygosity。

Space、1–4、N、F、Esc 保留；新增 `[` / `]` 選取並移至活體。按鈕焦點不被全域 Space 快捷鍵攔截。隱藏筆記使用 inert，展開／關閉移動焦點，控制提供 expanded / pressed 狀態與焦點框。Canvas 有替代說明；統計有文字值，不單靠色彩。滑鼠點選、拖曳、滾輪與 zoom 按鈕沿用。手機面板可捲動；完整螢幕閱讀器可用性、觸控縮放仍未驗收。
