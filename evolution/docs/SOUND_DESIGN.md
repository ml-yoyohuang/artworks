# Stage 4 聲音

環境音是一層安靜的藝術性聲化，不是細胞實際發聲，也不是用來推論演化原因的量測。預設不建立AudioContext、不播放；訪客按下「開啟環境音」才建立音訊。無網路素材、無音樂檔、無外部服務。

四個正弦振盪器使用固定的130.8128Hz基頻與1、1.5、2、2.5倍泛音關係，經低通濾波與低音量總線。音量初始35%，可調到0或關閉。各聲部緩慢滑入，不逐次出生發出提示音，避免擁擠時形成噪音。

| 實際資料 | 藝術映射 |
|---|---|
| 現存數量，密度在1800飽和 | 基底聲部的輕微強弱 |
| 三類現存比例 | 三個上層聲部的相對音量 |
| 兩類食物的容量加權總豐度 | 低通濾波開度 |
| 當下平均游速 | 小幅增加濾波開度 |
| 全滅、暫停、確認視窗或獨立研究 | 環境音暫停 |
| 隱藏頁面 | 立即靜音並暫停AudioContext；回來不播放積欠事件 |

更新最多每500ms一次；用數秒的參數過渡，不使用模擬亂數。反覆開關重用同一組節點，不重建無限振盪器；有dispose釋放方法，離頁先暫停音訊。瀏覽器拒絕音訊時顯示可理解的文字，生態箱不受影響。

實測Chromium反覆開關、音量鍵盤調整，以及播放時`running`／暫停後`suspended`。尚未進行耳機／喇叭的人工主觀聽辨或多裝置音量校準；不宣稱聲音已經通過主觀音質驗收。
