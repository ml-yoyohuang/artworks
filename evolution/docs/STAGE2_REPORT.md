# STAGE 2 修正報告（2026-11-12）

## 目前階段狀態

**主要實作完成，完整驗收尚未結案。** 觀察室、遺傳外觀、選取檢視、基本統計、環境介入與配色擴充已可使用，既有 30 個測試、型別檢查與建置通過。仍需補齊下方列出的 UI 快照往返、背景／減少動態與裝置等驗收，不能把本次提交等同於所有接受條件已通過。

三類生物、兩種資源，以及節能型可遺傳角數與多瓣型可遺傳瓣數，屬於已更新的 `prompt-stage3.md` 規格，尚未實作，也不是 STAGE 2 的未完成項目。節能型延續概念圖的圓角多邊形語言，並非固定六角形。`prompt-stage4.md` 為後續階段文件，納入版本控制不代表已開始實作。

## 已有功能

原先並非「Stage 2 全做錯」：科學引擎、概念圖衍生的水彩觀察室、基因外觀、個體檢視、追蹤與相機、統計、氣候介入、釋放／複製、快照與診斷頁都已存在。本次保留現有架構與未提交的工作，沒有推進 Stage 3。

## 本次變更

- 修正 seed=0、滅絕時間、替換世界時殘留的放置模式與插值相位。
- 重設與快照取代前顯示警告，檔案選擇器可重選同一檔案。
- 出生／死亡特效改用秒數且暫停時凍結；Canvas 支援減少動態偏好；肖像依真實速度擺動。
- 移除暗示死亡養分回收的粒子；澄清外觀比喻、放大尺度、感測範圍與死亡／繁殖規則。
- 修正不均勻歷史樣本的時間座標與事件位置；補統計尺度、單位、SD、樣本時間、當下資源與平均能量。
- 新增鍵盤選取個體、焦點框、隱藏面板 inert、展開／倍率語意，保留按鈕原生 Space 操作；處理 pointercancel。
- 明確定義背景暫停與高倍率降速，顯示實際 ticks/s、frame CPU 耗時；未修改科學步進。
- 快取肖像幾何／顏料與 2D fallback 暫存資源，避免每幀重建。
- Chronicle 使用文字節點，避免快照中的事件文字被當成 HTML。
- 橘、藍配色各增加三個相近色調，沿用中性遺傳標記連續內插；生物、肖像與檢視色票共用 `palette.ts`，預覽見 `cell-palette.svg`。此變更不影響科學狀態。

## 驗證

- 修改前原有 25 個測試通過；修改後 30 個測試（含原 25 個）通過。新增測試涵蓋 seed 0、歷史時間軸、滅絕事件、Clock 重設及外觀不消耗引擎亂數／影響後續確定性。
- `npm run typecheck`、`npm run build` 通過；診斷頁與藝術介面皆納入建置。
- 實際 Chromium 桌面與 390×844 視窗觀察：風格延續、面板與統計可讀；操作確認鍵盤選取、暫停維持 tick、筆記開關、64×實際速度、seed=0、重設確認會出現並可建立新世界。
- 高倍率觀察案例：seed 64297、約 656–735 個體、筆記及個體卡開啟，目標 1920 ticks/s，觀察實際約 528–545 ticks/s、frame CPU 約 33–35 ms。這是單次現場觀察，不是保證 FPS，亦不含 GPU 完成時間。

可重跑的 CPU 模擬量測：`npx vite-node experiments/benchmark-stage2.ts`。Windows、Node v16.14.2、seed 123，每組 3 次，每次先跑 30 ticks，再量 200 ticks；不固定人口，不改生態規則。原始資料：`stage2-benchmark.json`。

| 初始 founder 數 | 量測起始 → 結束人口 | 中位 ms/tick |
|---:|---:|---:|
| 200 | 200 → 181 | 0.207 |
| 700 | 694 → 595 | 0.691 |
| 1500 | 1483 → 1195 | 1.407 |
| 3000 | 2979 → 2110 | 2.661 |

這不是固定人口基準、renderer 或 GPU 基準；JIT 與同機負載會影響結果。沒有沿用 HANDOFF 的舊 GPU 數據作為本次驗證。

- 減少動態與背景頁面政策已實作，但尚未透過系統偏好／背景切換做完整 UI 自動驗證。

## 執行與檢查

在專案目錄執行 `npm run dev`，開啟 `http://localhost:5183/?seed=0`；診斷頁在 `/diagnostic.html`。

使用 `[` / `]` 選取，Space 暫停，N 開啟筆記，1–4 改倍率。檢查統計單位、樣本時間與實際 tick rate；Climate & experiments 提供實驗中介入，Save 保存完整狀態，New world 顯示取代警告。
