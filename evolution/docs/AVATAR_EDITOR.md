# 研究員造型調整工具

開啟 `http://localhost:5183/avatar-editor.html`，或點觀察員紀錄標題右側的研究員。這是獨立調整頁，不更改觀察箱進度；草稿不會自動套用主站。

## 這次造型

延續站務員的平面色塊與圓潤比例，增加蓬鬆不對稱捲髮。鏡片不透明、左右皆有反光帶，沒有眼睛圖形；嘴巴預設為弧度0的橫線，穿白袍並拿小燒瓶。仍全部是手刻SVG幾何，沒有點陣圖或圖片生成。

## 微調

| 部位 | 可調內容 |
|---|---|
| 捲捲頭 | 位置、寬高、捲髮團數、起伏、蓬亂、旋轉；雲朵／炸毛輪廓 |
| 反光眼鏡 | 位置、大小、間距、高寬比、粗細、旋轉；圓／圓角方／切角鏡框；反光亮度與寬度 |
| 嘴巴 | 位置、寬度、弧度、粗細、旋轉；橫線／小圓嘴／V形 |
| 臉型 | 位置、寬高、圓潤程度 |
| 白袍 | 位置、寬高；領帶、口袋與筆、鈕扣 |
| 配件 | 不拿配件／燒瓶／咖啡／筆記本；位置、大小與旋轉 |
| 顏色 | 頭髮與鏡框、臉、鏡片、白袍、領口與液體、領帶與筆記本 |

直接拖曳部位，或選取後在預覽上用方向鍵移動，Shift為5倍步幅。右側可用滑桿或輸入數值；下方有實際68×76大小的標題頭像預覽。提供最多50步復原／重做、個別部位還原及整體復原。畫布固定，極端位置或尺寸可能超框；大圖和匯出的SVG使用同一畫布邊界。

## 確認與交付參數

1. 調到喜歡的版本。
2. 按「複製參數」，把整段JSON貼回對話；剪貼簿不可用時會展開並選取文字，可自行複製。
3. 也可在「參數與匯出」下載參數檔或SVG，再匯入繼續調整。

參數格式為 `{schema:"evolution-researcher",version:1,parameters:{...}}`。所有欄位完整驗證型別、數字範圍、顏色及選項，錯誤匯入不取代既有草稿。本機草稿用獨立儲存鍵，與生態箱／觀察員文章無關。

收到確認的參數後，更新 `src/app/researcher-avatar.ts` 的預設值，再執行 `npm run avatar:export`，將同一份手刻幾何輸出為 `public/observer.svg`。工具和網站資產共用這份幾何來源，避免預覽與套用結果不同。

## 驗證

72個測試通過；新增參數往返、未知／缺失／注入／超界值拒絕、各形狀與極值有限數、不同預覽ID不衝突，以及主站SVG與預設渲染一致的測試。最後介面調整後另通過型別檢查與正式建置，輸出包含獨立 `avatar-editor.html`。

Chromium實際驗證：數值調整髮寬138／嘴寬20、方向鍵移動嘴巴、拖曳眼鏡改變座標、復原、切換雲朵／炸毛、複製參數、重新整理接續草稿，以及匯入嘴寬18的JSON。測試草稿最後已還原為這次的新造型。手機觸控拖曳尚未以真機驗收。

## 2026-11-12 確認造型與時間變化

已套用使用者回傳的49項參數（蓬鬆雲朵髮、橫線嘴、不露眼睛的反光鏡片、無領帶與鈕扣、配件傾斜−12度）。其中兩項依後續要求改為自動模式：

- `glassesShape: daily`：依瀏覽者當地星期，週一／四／日圓框、週二／五圓角方框、週三／六切角框。
- `accessoryType: cycle`：按實際時間每分鐘切換燒瓶、咖啡杯、筆記本，三分鐘循環。開啟頁面便顯示當前時間的配件；暫停生態箱、關閉播報仍照常更換，背景分頁返回時直接更新當前樣式。

主站以共用手刻SVG函式顯示動態造型；`public/observer.svg`為固定時間的備援圖。工具保留靜態形狀／配件選項，可預覽每一種。既有本機草稿不覆蓋；按「全部還原」可載入最新確認版本。下載SVG會固定為下載當下的樣貌；JSON則保留自動模式。

驗收：75個測試、型別檢查、正式建置通過。Chromium確認3.375×初始倍率、最小1×按三次加號回到3.375×、SVG星星收藏填色及取消、手機390×844工具列無超框。暫停時實際觀察到咖啡杯切換筆記本；星期與分鐘邊界另有自動測試。
