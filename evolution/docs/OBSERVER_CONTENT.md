## 動態欄位對照

以下名稱對應前面實況模板的括號欄位；實際播報會填入當次紀錄。

| 欄位 | 內容 |
|---|---|
| `{reason}` | 開始、重新開啟或切換觀察的原因，完整選項見下表。 |
| `{tick}` | 觀察起點的模擬步，以千分位呈現。 |
| `{population}` | 此次紀錄的現存個體數。 |
| `{type}` | 正在報導的類別：橘藍游動型、藍綠節能型或粉橘多瓣型。 |
| `{rival}` | 排名逆轉前，原本數量最多的類別。 |
| `{milestone}` | 剛跨過的人口門檻：100、500、1,000或2,000。 |
| `{before}` | 上一段紀錄的人口數。 |
| `{delta}` | 和上一段相比增加或減少的數量，填入正數，增減方向由句型表達。 |
| `{food}` | 藍色食物或綠色食物。 |
| `{amount}` | 食物存量佔容量的百分比，四捨五入至整數。 |
| `{consumer}` | 「偏愛這份食物的橘藍游動型」或「主要吃這份食物的藍綠節能型」。 |
| `{share}` | 正在領先的類別佔現存總數的百分比。 |
| `{actor}` | 類別加個體編號，例如「粉橘多瓣型的第 101 號」。 |
| `{change}` | 親子間的角數、瓣數或其他遺傳特徵差異，完整句型見下表。 |
| `{environment}` | 食物供應短句，見下表。 |
| `{ranking}` | 數量首位或並列的短句，見下表。 |
| `{births}` | 本段出生次數或資料不完整的短句，見下表。 |
| `{detail}` | 節能型平均角數、多瓣型平均瓣數及變化方向，見下表。 |
| `{absentTypes}` | 當下沒有現存個體的類別，以「、」串接；由觀察紀錄帶入，不寫死在台詞裡。 |
| `{presentTypes}` | 當下仍有現存個體的類別，以「、」串接；由觀察紀錄帶入，不寫死在台詞裡。 |

| 平均瓣數向上變化 | 多瓣型平均 〔平均瓣數〕 瓣，比上一段偏向更多瓣的外形 |
| 平均瓣數向下變化 | 多瓣型平均 〔平均瓣數〕 瓣，比上一段偏向更少瓣的外形 |

平均角／瓣數保留一位小數；與上一段平均值相差至少0.15時才加上變化方向。兩群都存在時以「；」串接，只剩其中一群時只報該群；兩群都不在時，使用「族群缺席巡查」的六種完整台詞。
