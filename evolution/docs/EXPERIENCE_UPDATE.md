## 概念圖內部構造

節能型移除外伸觸鬚，改為從能量核中心延伸、止於膜內側的細放射線與圓點，依角數產生；多瓣型移除外部觸鬚，每瓣有 0–3 個分散的實心粒子。粒子數由既有中性 marker 連續值推導，同基因／瓣數的 clone 一致，子代通常相近；不是增加基因 locus、感測器或功能性胞器。小突變可跨越顯示整數門檻，不能稱為功能適應。所有細節裁切在膜內、快取於 sprite，肖像／祖先預覽共用。選取時的三方向感測虛線仍是實際感測資料。

## 模型 3：最小轉動半徑

新世界預設 model 3，採 `R=max(minTurnRadius, 2×physicalRadius)`，預設 minTurnRadius=12 世界單位，`turn=clamp(controllerTurn×maxTurn, -speed/R, speed/R)`。零速度不轉動，不強迫前進、不添加能量，也不免除運動成本。離散 chord radius = speed/(2sin(abs(turn)/2)) ≥ R。世界邊緣仍夾取座標，因此此保證適用於未被邊界截斷的位移；沒有新增碰撞／反彈物理。

這會改變科學軌跡，所以另立 model 3。快照仍用 schema v2，可保存模型 1/2/3；舊 v1 與模型 2 快照保留原運動，不悄悄升級。既有 CLI G/A–F/long/benchmark 預設 model 2；`--model3` 另存帶 `-model3` 後綴的結果，不覆寫舊實驗。完整 manifest 依其 model 執行。
