# Stage 4 交接

## 本輪完成

三種觀看方式、可略過引導、命名世界／本機兩代自動保存／6份命名收藏、個體星號與暱稱、可匯出帶收藏資料的世界檔、損壞檔案保護、自願開啟且隨觀測休息的Web Audio環境音、雙指縮放程式、手機面板層次及暫停時按需重繪。既有三類生物與中文觀察員風格保留。

## 使用

在`evolution`執行`npm run dev`，開啟`http://localhost:5183/`；`npm run build`輸出`dist/`。`npm test`與`npm run typecheck`做回歸檢查。這一輪尚未部署或提交到遠端。

靜觀用於長時間觀看；探索時點生物、跟隨並收藏；研究可查圖表／譜系或做比較。音訊預設關閉。收藏庫會提醒是否接續上次，不會默默用新的觀察箱覆蓋。重要進度請另匯出，清除瀏覽器資料會失去本機收藏。

## 檔案

- `world-record.ts`：應用世界封裝與校驗、IndexedDB原子備份。`archive.ts`：收藏與續看介面。
- `experience.ts`：模式、引導、全螢幕與聲音控制。`sound.ts`：只讀的和聲映射。
- `main.ts`：保留原科學步進，加入整合、雙指操作、鏡頭時間平滑與按需重繪。
- `tests/stage4.test.ts`：保存／延續／拒絕損壞／音訊只讀驗證。
- 本階段決策與證據：`STAGE4_AUDIT.md`、`ART_DIRECTION_FINAL.md`、`INTERACTION_DESIGN.md`、`SOUND_DESIGN.md`、`QUALITY_REPORT.md`。

觀察員只留本次瀏覽的要求不變。世界檔案封裝不包含觀察員文章；舊的科學快照仍可載入。收藏暱稱與觀察員的生物學敘事，不是額外的功能基因。
