# 觀察員頭像與資料介面語言

## 頭像

`public/observer.svg` 為手刻幾何輸出，164×184畫布；沒有使用圖片生成、外部點陣圖或內嵌image。依創作者提供的「站務員」參考圖保留圓潤與扁平色塊的吉祥物比例。最新版本有更蓬鬆的捲髮、不透光反光鏡片（不畫眼睛）、橫線嘴巴、白袍與小燒瓶；不使用寫實鼻耳或膚色明暗。來源與可微調工具見 `AVATAR_EDITOR.md`。

將68×76px頭像放在「觀察員紀錄」標題右側，與關閉按鈕留開距離；點頭像會另開造型調整工具。連結有獨立的無障礙名稱，內部img使用空alt，獨立SVG內有title。

移除「小世界的現場筆記」，保留簡短狀態與播報控制。說明精簡為：「最多 200 行。觀測進行時定期記錄，重大發現隨時插播。」完整台詞集的介面說明已同步。

## 中英切換

工具列新增「中文／EN」選單。無已存偏好時預設中文，偏好記在本機；儲存不可用時仍可切換。範圍為研究筆記、環境與實驗、個體資料及相關比較結果、家族資料、檢查點、刻度與輔助標籤。研究讀數、名稱與原始匯出資料不因語言改寫。

`i18n.ts` 為輕量靜態文案綁定與動態雙語字串選擇；不每幀掃描整個DOM、不以翻譯替換控制元件，因此不破壞選單、按鈕事件、輸入內容或canvas。切換觸發目前面板的重繪，不重建科學世界、不重開觀察員文章。三個資料面板各自標示lang，整頁仍維持中文，讓中文觀察員文章正確朗讀。

觀察員文章、導覽、收藏庫與聲音面板維持現有中文語氣。這是資料介面的雙語切換，不宣稱所有內容均已完整英文化。早期診斷工具頁仍保留原語言。

## 自訂選單與勾選框

`select-control.ts` 將主頁的五個select（語言、播報間隔、食物、新住客、比較項目）連接到自訂combobox／listbox；原select隱藏並保留值、disabled及既有change事件。展開後是紙色、深紫勾選記號與藍綠反白的頁內選單，不是作業系統選單。可用時使用Popover頂層呈現，否則用固定定位；會依視窗空間翻至上方，面板捲動、點外側或確認視窗開啟時收合。

支援方向鍵、Home／End、Enter／空白鍵確認、Escape取消、Tab離開與文字搜尋。焦點保留在combobox，aria-expanded／aria-activedescendant／aria-selected對應狀態。原始select的局部MutationObserver同步翻譯及disabled，未掃描整份文件。勾選框沿用真正checkbox的鍵盤和標籤語意，以appearance:none與手刻勾號自訂外觀，含焦點、停用與高對比規則。

實測鍵盤選擇20秒後，另開選單移至10分鐘並Escape取消，值仍為20秒且觀察員面板保持開啟。空白鍵可關閉／重開播報。自訂語言選單同步中英文字、食物選單可換至B，新住客可選多瓣型，研究比較可換到突變條件並實際跑完兩次100步實驗。沒有宣稱完整讀屏或跨瀏覽器驗收。

手機390×844實測：五個原生select均隱藏，checkbox的appearance為none，自訂間隔選單的左右邊界在視窗內，沒有水平溢出。當前研究員與控制元件圖為 `researcher-controls.png`，`observer-avatar-panel.png` 同步更新。
