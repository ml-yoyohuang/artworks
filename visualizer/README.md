# 聲音放映室 · Music in Motion

目前共 34 個 MP3 視覺預設，含 rhythm 兩組共 26 件與主題選集 8 件。選擇紀錄見 [SELECTIONS.md](SELECTIONS.md)，正式資料見 `presets/selections.json`。新增內容全部位於 `visualizer/`；`rhythm/vol1/`、`rhythm/vol2/`、`sound/test1/`、`sound/test2/` 與 `_incoming-assets/` 不需修改。

## 本機執行

在 artworks 根目錄執行：

```sh
python3 visualizer/tools/serve.py
```

開啟 http://127.0.0.1:8788/visualizer/ 。需要 HTTP，不能直接使用 file://。此預覽伺服器支援 MP3 的 byte-range 讀取，讓進度跳轉正常運作。沒有 npm install、編譯或 CDN。

預設曲目是本機 `../_incoming-assets/free-mp3/Disfigure - Blank [NCS Release].mp3`。頁面載入不播放、不建立 AudioContext；按播放才開始。測試清單讀取該資料夾的 10 個檔案，沒有搬移或重新保存原音檔。其他機器沒有這些檔案時，使用「開啟 MP3」或拖入自己的音檔即可。

音檔只在瀏覽器播放與分析，不錄音、不請求麥克風、不上傳。測試音樂沒有複製到 visualizer，也未發布。

## 操作

- 按播放／暫停；拖曳歌曲進度；調整音量與靜音。
- 前後箭頭或「視覺收藏」切換 34 個預設，歌曲不中斷。
- 全螢幕、保存當前畫面 PNG。
- 拖入音檔或選取多個音檔，從本機播放清單切換。
- 設定反應強度、動作平滑、視覺節奏與每 30 秒自動換預設。
- 空白鍵播放／暫停、左右鍵換視覺、M 靜音；操作表單或對話框時不攔截這些快捷鍵。

靜音與音量在分析分支之後，畫面不受輸出音量影響。暫停凍結歌曲與材料。Seek 與换曲清空當前材料，從新位置重新形成；不重建先前整首歌的歷史。背景分頁自動暫停，回來需按播放。

## 已完成的第一版範圍

34 個预設都保留原本畫法；`sources/` 是從四個原作資料夾複製、再在新資料夾內改造的來源。四個 adapters 把同一套音訊特徵交給不同場景。原作的自動合成發聲與音訊排程器不啟動，MP3 不會混入原作聲音。

- sound 16 件：角色、波形、彈性、節拍粒子、頻段燈光、音樂塗鴉。
- sound2 10 件：用 MP3 起音替換原譜事件，能量控制動作幅度；保留接力、慢半拍與周期編舞。紙瓣花各圈獨立讀頻段。
- test1 選定 3 件（01、03、06）：Canvas 材料模型以頻段、包絡、起音與低能量段形成材料。
- test2 選定 5 件（02、04、05、07、08）：原本 Three.js／GLSL／Canvas 的幾何與材質；MP3 專用相位、能量、切口、織布、視覺回聲與分段標本。

sound4 化石從空白開始，只有聲音才新增螺形截面，沒有底座、立架或預成形螺。沿對數螺旋持續向外長，不依曲長停止，也不每 44 秒重置。節奏快慢影響生長速度，音樂能量僅小幅微調；8 個頻段與起音形成每個新截面的紋路。鏡頭隨整體尺度退遠；使用相對座標避免長時間生長的數值溢位。保留最多 2048 個截面，超過時只疏化早期截面的細節，保留起點與最新 512 個截面，不重播、不覆寫已長出的聲音。雕塑依有限截面與停頓定型，保留有限舊件。織布、泡泡、漣漪與回聲事件各有數量上限。

無 WebGL 时，test2 的 WebGL 預設使用已選定 test1 共振建築的即時 Canvas 替代，畫面文字明確標示，歌曲仍繼續。不是使用靜態縮圖代替律動。

## 音訊分析與限制

HTML audio → MediaElementAudioSourceNode；一條分支去音量輸出，一條分支去左右聲道 FFT 分析。左右功率合成避免反相聲道互相抵銷；波形展示使用能量較高的聲道。

分析包含 RMS、8 個頻帶、平滑包絡、頻譜亮度、粗糙度、頻段起音與簡易節奏信度。特徵即時分析，無全曲解碼記憶體需求。視覺狀態推進依媒體時間增量；畫面最高約 45 fps、DPR 上限 1.5，部分 Three 場景更低。減少動態偏好降至 15 fps 與各場景的減動設定。

這是能量／起音驅動的第一版，未實作完整旋律轉錄、樂器分離、和弦辨認、真正的樂句／小節辨識。chroma、離線特徵時間軸、精確輸出延遲校正、歷史 checkpoint 與 MP4 匯出不在本版。簡易節奏估測不是專業 beat tracker；信度不足則用起音／能量，仍保留作品自己的周期編舞。

同一 seed 只決定初始構圖；即時分析的累積結果會受瀏覽器與幀率影響，未宣稱跨裝置逐值可重現。

## 結構

```text
index.html / style.css / app.js    播放器、收藏、音樂選取與控制
 audio/player.js                  唯一音訊來源與播放生命週期
 audio/features.js                左右聲道能量、頻段、起音與節奏信度
 audio/tracks.js                  本機測試曲目相對路徑（沒有音檔）
 runtime/preset-host.js            切換、媒體時鐘、尺寸與替代模式
 adapters/                        四組原作的 MP3 轉接層
 presets/registry.js              全部 34 件資料
 sources/                         僅在此處修改的原作副本
 vendor/three/                    原作已本地化的 Three.js，保留 MIT LICENSE
 previews/                        原作或清理後的靜態縮圖，只用於收藏卡片
 tools/                           建立與實際瀏覽器驗收腳本
 _qa/                             原檔案指紋、驗收與實際畫面
```

`tools/prepare.py` 與 `tools/adapt-sources.py` 是這一輪來源建立工具；不必為了日常使用重跑。後續請直接編輯新資料夾內來源；重跑建立工具會覆蓋副本。

## 驗證

本機 Playwright 腳本放在 `tools/acceptance.cjs`。執行時需已有 Chromium 與 Playwright，並先啟動上述 HTTP 伺服器。腳本頂端的 Playwright 路徑可改為自己的安裝位置。

```sh
node visualizer/tools/acceptance.cjs
python3 visualizer/tools/verify-originals.py
```

驗收結果與限制以 `QA_REPORT.md` 和 `_qa/acceptance.json` 為準。原檔指紋比對是本輪未修改舊檔案的證據，不是 Git 狀態或原音檔的備份。

## 休止符的相對留白（2026-10-12）

兩版休止符改用 `audio/music-dip.js` 偵測音量回落，不再要求接近全靜音。以原始 RMS 的 80 ms 包絡對照最近 3 秒平均與衰減峰值；低於平均的 88% 或近期峰值的 78% 約 0.16 秒就觸發。開口至少保留 1.8 秒，回升維持 0.18 秒後收束，兩次切開至少相隔 3 秒。這是音樂中的相對留白，並非聲音完全停止。其他作品的全靜音判定維持原樣；輸出音量、靜音不影響判定。暫停凍結，換曲／跳轉清空判定歷史。

## 化石生長速度（2026-10-12）

生長速度改由最近 9 秒節奏起音間隔的中位數決定，至少三個有效間隔才採用新估計，保留 40–180 的視覺節奏範圍；較少起音的持續段慢慢減速。速度約以 2 秒節奏平滑加 1 秒速度平滑過渡，音樂能量只帶來約正負 5% 的速度變化。這是起音頻率估計，不是完整節拍辨識；分拍或弱拍仍可能影響估計。紋路、材質與打光保持還原後的版本。

## 主題擇一收錄

按 `presets/selections.json` 選定八件，淘汰的另八版不註冊、不出現在收藏與輪播，也不作 WebGL 替代。來源 `sound/test1/` 與 `sound/test2/` 不修改。重建來源時 `tools/prepare.py` 會套用 `tools/select-presets.py`，保持選擇。

## 拍點開花與單向迷宮（2026-10-12）

能量蓄積的 MP3 轉接器採 beat gate：蓄滿後鎖住已蓄能量，等下一個單拍才啟動釋放。節奏信度足夠時使用平滑拍點時鐘並靠近起音校正；不足時使用有效起音，不在全靜音中自行開花。以單拍為單位，不假定三拍或四拍的小節；未辨識每小節第一拍。開花本身仍保留原有展開動畫。

回聲迷宮補上回聲到達時的牆面揭露紀錄；以廣度優先搜尋選擇最遠可達格，沿最短通道路線逐格前進，每座路線不重複經過格子。起音較稀疏時，仍在有聲段最多約 1.5 秒前進一步。到達終點、完成移動並短暫停留後換新迷宮。這是通往遠端的一條路線，不要求走遍所有分岔房間。
