## 策展與設計判斷

系列命名為「小小聲音遊樂場 / Soft Scores」。以溫暖紙色、宋體標題、DM Sans 拉丁文字與膠囊控制元件建立共同語言；珊瑚、芥黃、鼠尾草綠、霧藍與淡紫形成接近套色印刷的色盤。各作品使用不同場景底色與獨立構圖，保留空氣與安靜的等待，避開黑底霓虹頻譜的慣例。

採原生 Canvas 2D + **Tone.js 15.0.4**。這組媒材足以呈現線條、碰撞、紙感與柔軟物理，不需要 WebGL 或更重的視覺函式庫。唯一外部程式庫與 DM Sans 字體均從固定版本的 CDN 載入，沒有 latest 或版本範圍。

預設安靜排練；「開始聆聽」才呼叫 Tone.start() 與建立樂器。主旋律是五聲音階，依作品改變正弦、三角、方波或鋸齒音色，節奏作品另用合成低音鼓與粉紅噪音。輪唱有三個錯開聲部；節拍器的六個音符會在二十秒內逐漸同步。Tone.Transport 提供節拍時鐘，Tone.Draw 對齊拍點的畫面事件；波形與擺動則保留連續的自主運動。

## 操作、相容性與效能

各頁都有返回目錄、標題、兩至三句作品說明、開始／暫停聲音、靜音／播放聲音、暫停動態、節拍滑桿與前後作品連結。滑鼠、觸控與鍵盤均可使用；畫布聚焦後方向鍵改位置、Enter 加一拍、空白鍵切換聲音。所有作品與目錄內部連結均為相對路徑。

手機改成方形展示框與直向策展側欄；指標座標依作品在框內的實際縮放與留白換算，不會把空白邊緣當成錯誤落點。`prefers-reduced-motion` 在首次載入與動態切換時均停格，聲音可以獨立運作；音訊拍點不會在停格時偷偷增加移動。觀眾自己的操作仍可更新畫面。

畫布像素倍率上限為 2；粒子、漣漪與手繪軌跡均有固定上限。沒有逐幀 DOM 大量增刪，背景頁面不跑 rAF。頁面隱藏時會自動暫停聲音，返回後由觀眾自行恢復；離開頁面會清除時鐘事件並釋放樂器。目錄使用 16 張輕量靜態 WebP 與少量 CSS 動畫，沒有 16 個同時運行的 canvas。

## 重製與驗證

網站可直接靜態託管，不必執行以下製作工具。

```sh
python3 sound/tools/scenes.py
python3 sound/tools/build.py
python3 -m http.server 8765 --bind 127.0.0.1
# 另開終端，使用已安裝 Playwright 的 Node.js 環境：
node sound/tools/verify.cjs --thumbs
python3 sound/tools/thumbnails.py
node sound/tools/verify.cjs
node sound/tools/resilience.cjs
python3 sound/tools/contact.py
```

若 Playwright 不是一般 node_modules，可設定 `PLAYWRIGHT_MODULE` 為其絕對路徑。Python 的縮圖／檢視工具需要 Pillow。`SOUND_URL` 可指定其他本機靜態服務網址。
