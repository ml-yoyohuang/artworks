## 初版驗證方法

採 Playwright / Chromium 瀏覽器實測，並以 SwiftShader 與 Apple Metal 兩種繪圖後端檢查。嘗試執行 Chromium 安裝命令後，使用環境既有且可正常啟動的 Chromium 1234；沒有任何「僅靜態檢查」或「未經瀏覽器實測」頁面。

- 全部 17 頁以 `file://` 開啟，每頁至少運行 3.3 秒，分別擷取 1440×900（DPR 1）與 390×844（DPR 2、觸控）的畫面，共 34 組最終檢查。
- 監聽 console error 與 pageerror；直接讀取 canvas 多處像素，量化 RGB 後確認顏色變化，排除全黑、全白與單一顏色。Bayer 的有限色階是作品特性，並非失敗。
- 強制 WebGL1 並關閉所有 float / half-float 擴充，逐頁運行至少 3.1 秒；另外逐頁測試 `prefers-reduced-motion: reduce`，確認畫面具有內容。以相隔 350ms 的畫面雜湊確認 16 件作品在低動態模式中保持靜止。
- 16 件作品逐一操作滑桿、按鈕、觸控、游標與收合說明，確認控制項及面板在 390px 畫面內。觸控播種會保存短暫按壓，避免快速點按被漏掉。
- 逐頁觸發 `visibilitychange` 並模擬 hidden 狀態，比較緩衝內容確認暫停。此項為事件與繪圖生命週期測試，不是實際多分頁排程測試。
- 模擬無 WebGL 及 shader 編譯失敗；作品顯示繁體中文原因與建議，目錄則顯示靜態背景說明。沒有空白頁。
- 另以本機 HTTP 靜態伺服器開啟 17 頁，確認零 console / pageerror。目錄 16 個作品連結與 16 張圖片皆正常載入；內嵌程序化 favicon 避免靜態伺服器的 favicon 404。
- 靜態檢查 HTML 語言、獨立資產、相對連結、控制數量、DPR 限制、動態偏好、暫停事件與觸控事件；所有檢查通過。GLSL 由實際 WebGL1 與 WebGL2 驅動完成編譯與連結。

## 視覺評審與修正

逐一檢視 16 頁桌機與手機截圖，並以聯覽接觸表比較作品辨識度、留白、色帶與文字份量。紙面漸層、大理石、網點肖像、數學雕塑、銀鹽、雙色花園、藍曬、光軌與織紋各有不同主體；回饋刻意採大量暗部與微弱光源，保留安靜的夢境感。

修正了珊瑚初期增殖過快而鋪滿畫面的問題，改以具有方向性的生境限制和稀疏鄰居規則維持中心聚落；它採不可逆細胞佔領，明顯區別於 Gray–Scott 化學反應。暗房提高初期顯影曲線的可辨識度並調整文字對比。手機增加構圖視野，讓雕塑、肖像與玻璃保留完整形體；Bayer 肖像亦獨立調整採樣座標，並以紙色標籤維持網點上的文字與按鈕對比。修正後均重新截圖驗證。

## 初版效能

以 Apple M4 Pro / ANGLE Metal 在 1440×900、DPR 1 的 Chromium 量測，16 頁在初始運算之後，各取約 1.6 秒 requestAnimationFrame 間隔，均約 120fps，測試時無 WebGL 錯誤。這是此設備的穩態繪圖排程結果，並非所有一般筆電或手機的保證。

DPR 上限 2；窄螢幕預設採 0.66 的解析度比例。持續較慢時逐級降低畫面解析度，最低為起始比例的一半。反應擴散最大邊 320px、細胞生長 420px、排序 768px、光線累積與回饋 960px，避免以螢幕全解析度執行多 pass 模擬。

## 自行決定與理由

1. 使用「光與物質」作為策展主題，介面退到四周，以系統繁體中文字體呈現；每頁只保留最有意思的兩至三個操作。
2. 色帶定義為三至四個主色錨點，允許漸層、陰影、顆粒、疊色與色散產生中間色，以保留實體材質的連續色階。
3. WebGL2 優先；同一份相容 GLSL 在 WebGL2 轉成 GLSL ES 3.00，在 WebGL1 以 GLSL ES 1.00 編譯，無套件依賴。
4. 浮點格式依擴充與 framebuffer 完整性決定，依序嘗試半浮點、浮點與 RGBA8；沒有擴充時仍執行同一類真實 ping-pong 運算。
5. 像素排序採 GPU 奇偶轉置交換，每段最多 64 個水平像素，亮度門檻分隔序列。初始化即完成可辨識排序，後續分攤 pass；按鈕及門檻變更重建原始圖像再排序。
6. 回饋與長曝光在開啟時預先累積少量歷史，讓初見也有完整作品。低動態模式預先建立靜態樣本並停止常態動畫，使用者仍可操作控制項。
7. 遠端在開始時為空 repository，main 尚無提交；沒有可落後的遠端 main。開始時的未追蹤 `p5-demos/` 保留；製作期間另一個工作流程將它提交至 main。提交前再次 fetch 確認本地與遠端 main 一致，且所有後續 `p5-demos/` 變更與 `.DS_Store` 均未納入本任務。

## 已知限制

- 沒有 float / half-float 可渲染紋理時，RGBA8 的化學反應會有較明顯量化，斑點擴張更緩慢；回饋與曝光的暗部會較快消失，長期殘留也可能因精度而略有不同。
- 細胞生長刻意保留格點的微小孔洞，屬生成藝術的生長模型，不是生物物理模擬。像素排序限制為局部亮度排序，而非整行全域排序。
- 手機驗證為 Chromium 裝置尺寸、DPR 與觸控模擬，未使用實體 iOS / Android 裝置，也未實測 Safari。不同 GPU 的浮點雜訊與幀率可能造成局部形態差異。
- 原生 Metal 效能量測使用 M4 Pro，不代表低階手機或所有一般筆電；解析度降級與模擬大小上限已實作。
- 使用 reduced motion 時顯影固定在可辨識階段，「重播」亦維持靜態；回饋及光軌展示預先累積的時間切片。
