- 平均 **59.96fps**；最低 **59.8fps**；最高 **60.0fps**。
- 390×844 手機視窗再次量測為 **60.0fps**。

- 已驗證游標、觸控、隱藏分頁停止更新及再次顯示後恢復。靜態作品完成後與減少動態結果均停止繪製。

## 重要決定與修正

1. 系列統一命名為「規則的餘溫」，以安靜的頁緣文字與兩個控制按鈕，讓作品保持主角。不同作品有自己的構圖、密度場、色帶及筆觸；共用的是排版規格與系統字體堆疊。
2. 大結構先被設計：流場採三束風帶；地形有三座山丘；切割保證一個紅色主體；圓形聚落保留偏心空洞；枝條採固定樹冠；點描採程序生成天體。隨機只改變局部細節。未知或不可靠的藝術史指涉沒有加入。
3. 靜態作品以約 14 秒逐步完成，之後 noLoop。減少動態時隱藏中間畫面，分批計算完成後直接呈現定稿，避免快速的視覺變動。
4. 背景紙面、已完成筆跡與固定字形使用 createGraphics；圓形停止生長後轉入固定緩衝層。差異生長、空間殖民、Voronoi 與圓形填充採均勻網格；計算被切成每影格的小批次，較重的鄰域運算另限制約 5–6 ms 的批次時間。
5. 手機依尺寸降低節點、吸引點、圓與 Boids 數量；字體在直向畫面重排為 FO / RM。各頁 CSS 與 JS 內嵌，只有 p5 函式庫共用，維持獨立單一 HTML 與離線開啟能力。
6. 首輪視覺審查淘汰了過於平滑的差異生長結果，調整增殖與排斥後才通過；切割改為固定一個紅色焦點；擴大畫面底部留白。互動測試也修正了 resizeCanvas 提前繪製已移除緩衝層的問題，以及分頁隱藏時可能殘留的一次影格回呼。修正後重新驗證。
7. 種子以無號 32 位元整數處理；有效 `?seed=` 可重現，超出範圍則取模，缺少或無效參數由瀏覽器加密亂數產生新種子。重新生成同步更新網址與角落標示。
8. 完整截圖、測試腳本、下載測試 PNG、種子比較圖與驗證 JSON 都放在 repo 外的 `/private/tmp/p5-art-verification/`；只有壓縮縮圖放入 `thumbs/`。沒有加入安裝產物或 node_modules。

## 已知限制

- 60fps 數據來自此環境的 Chromium；390×844 是手機視窗與觸控模擬，沒有宣稱已在實體手機、Safari 或 Firefox 做效能實測。裝置效能與省電模式仍會影響速度。
- 不同尺寸會重新策展元素數量與布局；系統字體及抗鋸齒會因作業系統而稍有差異。同種子的精確像素重現以相同瀏覽器與尺寸為範圍。
- 加權 Voronoi 以密度樣本近似重心，並非精確解析積分。它保留 weighted Lloyd relaxation 的原理，換取離線網頁的平順度。
- Boids 是持續動畫，時間與互動會影響截圖；減少動態模式提供固定步數的定格。PNG 下載的是當下藝術畫布，包含紙面與筆跡，不包含 HTML 介面文字。
- 非常矮的視窗仍保留最小作品高度；正式驗證範圍為指定的兩種尺寸。沒有對所有未知種子或所有硬體作無限範圍保證。
