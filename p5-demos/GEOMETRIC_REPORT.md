## 核心互動與實作

1. **領土協商**：十個葉區域組成二元分割樹。靠近或選取區域，調整祖先的共享切割比例；最小尺寸限制避免退讓造成非法尺寸。再次選取或 Esc 解除。
2. **尚未對準的印刷**：三個獨立快取色版以乘色疊印；原生進度滑桿接手，繼續觀看恢復 32 秒時間軸。乘色是程序油墨美學，不是物理印刷模擬。
3. **平面有背面**：五片大小不同的面繞固定鉸鏈做 3D 頂點旋轉，再投影到 2D。法線決定正反面，平均深度決定遮擋順序；每次只翻一片至 122 度。
4. **空白正在移動**：快取前景與下層，以 destination-out 在離屏前景真正挖洞。游標或輕觸接手自主路徑，三個位置可直接切換。
5. **色彩沉積**：9–11 層固定資料直接映射進度，往返不累加物件。滑桿與 Home／End 控制；減少動態模式初始顯示最終沉積。
6. **遲到半拍的群舞**：24 個固定模組分三組，其中四個延遲約 0.35–0.58 秒。留住群組只凍結其局部時鐘，解除後逐漸合流。減少動態改為兩個完整姿態的離散切換。
7. **同一張圖的不同尺度**：固定種子與路徑決定同一棵構圖樹，連續相機進入局部；上一層及全景可返回。最大五層、快取最多 512 節點、每次最多繪製 240 個可見節點。
8. **幾何的餘溫**：三個主體與最多八筆歷史姿態分開儲存。只在有意義的移動距離後記錄，歷史約十二秒消退；暫停與匯出保留當前痕跡。

所有作品均有畫布鍵盤操作、觸控等價操作、暫停／繼續、回到初始及下載 PNG。作品敘述、互動提示與控制保留為正常 HTML；八份論述各約 101–106 字。

## 沿用架構與重要決定

- 沿用既有靜態 HTML 路由、本地 **p5.js 1.11.11** 與 [授權檔案](lib/LICENSE.txt)。八件皆為 p5 instance mode；依此版本官方原始碼確認 createGraphics、resizeCanvas、saveCanvas、isLooping 及合成 API。未新增網站執行依賴，也無外部字型或圖片請求。
- 八份獨立場景工廠寫在各 HTML。共用 [exhibit.js](assets/geometric/exhibit.js) 管理生命週期與控制；[exhibit.css](assets/geometric/exhibit.css) 沿用系統字體、紙色展場與安靜標籤。程式碼已格式整理，維護時可直接修改各頁的場景與 metadata。
- 保留原有十張作品卡的 HTML、圖片、路徑與作品頁，新增「幾何之間」章節。同步更新目錄的十八件文字及 1200×630 [分享封面](assets/og-image.jpg)。未更動其他作品集與個人資料。
- 桌面並置畫布與標籤；760px 以下採直式構圖，重新計算幾何。768px 平板仍保持橫式畫布，避免圓形被壓扁。作品配色固定，系統深色模式只改外圍介面。
- 首次進入就是成熟構圖。只有有限比例、位置與延遲使用種子，避免逐影格抽樣造成漂移。色帶與形狀角色固定。
- 現有獨立海報式頁面不適合捲動劇場，因此套印與沉積採各一個原生滑桿；保留自然頁面捲動。畫布 touch-action 為 pan-y，手機以輕觸承接指標互動。
- 主畫布 pixelDensity 上限 2；離屏設計緩衝密度 1。靜止時 noLoop；持續動畫在離開觀看區或分頁不可見時暫停，不追趕背景時間。移除頁面時清理事件、觀察器與全部畫布。
- 16 張真實畫布 WebP 用於八件桌面封面與手機靜態替代圖；每張約 2–10KB。JS、p5 載入或 Canvas 失敗時仍有實際作品圖片及文字，沒有佔位圖。
- 未找到適用的 AGENTS.md、CLAUDE.md 或 CONTRIBUTING.md。沿用 lib/README.md 記錄的版本，並遵守本次委託；未更動原先存在、與本任務無關的 shader-demos2/。

## 已執行的驗證

實際使用 Playwright＋Chromium **151.0.7922.34**，開啟 file:// 本地頁面。主驗證 318 項檢查，另補做 Canvas 失敗、快取壓力、背景暫停及格式整理後複驗；正常頁面 console／pageerror 均為 0。

- 八件各六個固定種子，共 48 個候選畫布，逐件檢視候選及三個關鍵狀態。種子比較時為 1440×900、?still=1；翻折候選額外開啟第一片。
- 各件三個狀態：領土全景／主區擴張／橘區擴張；套印對準／分離／中段；翻折合上／約半開／背面展開；空白三個位置；沉積 0.66／0.5／1；群舞 t=8.7／2／17.4；遞迴全景／第一層／第二層；餘溫初始／矩形移動／圓再移動。
- 全部測試 1440、768、390、320 CSS 像素寬度，取樣像素確認不是空白或單色，並保存完整頁面截圖。檢視深色外圍介面與 reduced-motion 靜態停格，確認無水平溢出。
- 實際鍵盤、觸控點選、Canvas 上的自然縱向滑動、暫停／繼續、重置、尺寸改變、十二次重新進入與重新整理均通過。
- 每件 PNG 下載後比較原始像素與當前畫布，完全一致；輸出不含介面，檔名含 slug、種子與時間。
- 領土多次選取保持面積完整且尺寸正值；套印及沉積在相同進度往返得到相同像素；群舞的局部凍結與恢復沒有瞬間跳位；遞迴返回全景為相同像素；餘溫歷史上限八筆。
- 遞迴連續 330 次五層探索，快取達 **512／512** 後仍維持上限；測試終點可見節點 5／240。最大深度五層有效。
- 四件持續動畫在桌面 1440×900 各量測六秒，實測約 60fps，如上表。這是此測試環境的觀察，並非所有裝置效能保證。
- JS 關閉、p5 載入失敗及 Canvas getContext 回傳 null 三種情況，八件均能顯示實際靜態圖與說明；Canvas 不可用時也未產生未捕捉錯誤。
- 全部十八個作品入口與目錄縮圖、各新頁前後連結、共用資源存在。原有十張作品卡與變更前逐字比較一致。檢查所有新頁內嵌 JS、共用 JS 語法以及 git diff --check。

完整尺寸截圖、測試下載、候選與測試腳本均位於 repo 外的 `/private/tmp/geometric-artwork-review/`；網站只包含壓縮封面與正式資源。開發可用 `?seed=固定整數&still=1&t=指定秒數` 重現停格。套印及沉積另支援 `progress`，領土支援 `focus`，遞迴支援 `node`。

## 已知限制與交付狀態

- 測試為桌面 Chromium 及其手機／觸控模擬；尚未在實體 iOS、Android、Safari 或 Firefox 驗證，也未做螢幕閱讀器實機測試。
- Headless Chromium 分頁保持 visible，故背景測試是透過 visibilitychange 路徑模擬不可見與恢復；離開觀看區的暫停則是實際捲動驗證。真實作業系統的背景分頁尚未實測。
- PNG 為目前畫布解析度，沒有另設超高解析輸出。網址可直接開啟與重現初始種子；未把所有自由拖曳歷史或瞬間翻折角度完整編碼進分享網址，這些狀態請以 PNG 保存。
- 遞迴刻意限制五層，並非無限細節。系統清理暫存目錄後，完整審查截圖可能消失；保留的種子與狀態可重新產生。
- 使用者後續已明確授權 commit 與部署，取代初始委託的「不自動發佈」限制。沿用現有 GitHub Pages 設定，由 main 分支根目錄發布；沒有改動部署架構。
